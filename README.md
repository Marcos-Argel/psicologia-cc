# Psicología y Psicooncología C.C.

Sitio web oficial del centro **Psicología y Psicooncología C.C.**, un espacio especializado en psicología clínica y psicooncología dedicado al acompañamiento emocional de pacientes con cáncer, sus familias y personas que buscan apoyo en salud mental.

🔗 **Sitio en vivo:** https://marcos-argel.github.io/psicologia-cc/

## Descripción

Página web de una sola sección (*one-page*) que presenta los servicios del centro, su filosofía y proceso terapéutico, y permite agendar una cita directamente por WhatsApp mediante un formulario interactivo.

## Tecnologías

- **HTML5** — estructura semántica y metadatos SEO
- **CSS3** — estilos, diseño responsive y animaciones
- **JavaScript (Vanilla)** — interactividad (menú, tabs, acordeón, modal, formulario)
- **Google Fonts** — Cormorant Garamond y Montserrat
- **Schema.org (JSON-LD)** — datos estructurados para buscadores

## Características principales

- Navegación fija con resaltado automático de la sección activa
- Menú responsive tipo hamburguesa para móviles
- Sección de Misión, Visión y Valores con pestañas
- Catálogo de servicios con modal de detalle por cada uno
- Preguntas frecuentes en formato acordeón
- Formulario de agendamiento que genera un mensaje prellenado y redirige a WhatsApp
- Botón flotante de contacto directo por WhatsApp
- Animaciones de aparición al hacer scroll

## Ejecutar localmente

No requiere instalación ni servidor backend:

1. Clona el repositorio
   ```bash
   git clone https://github.com/Marcos-Argel/psicologia-cc.git
   ```
2. Abre `index.html` en el navegador, o sírvelo con una extensión tipo *Live Server* para recarga automática.

## Despliegue

El sitio está publicado de forma gratuita con **GitHub Pages**, desplegado directamente desde la rama `main`.
